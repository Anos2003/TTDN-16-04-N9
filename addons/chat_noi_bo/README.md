# Module Chat Nội Bộ

Hệ thống chat nội bộ công ty với đầy đủ tính năng.

## Tính năng

- 💬 Tạo phòng chat cho nhóm, dự án, bộ phận
- 👥 Thêm nhân viên từ Quản lý Nhân sự
- 📊 Mỗi dự án có phòng chat riêng
- 📝 Gửi tin nhắn text và file đính kèm
- ✅ Theo dõi trạng thái đọc
- 🔔 Thông báo tin nhắn mới
- 😊 Reactions (emoji)
- 💬 Reply tin nhắn

## Cài đặt

1. Copy module vào thư mục addons
2. Cập nhật danh sách module
3. Cài đặt module "Chat Nội Bộ"

## Sử dụng

### Tạo phòng chat
- Vào menu Chat Nội Bộ > Phòng chat
- Click Tạo mới
- Chọn loại phòng chat và thêm thành viên

### Chat cho dự án
- Vào module Quản lý Dự án
- Mở dự án
- Click nút "Chat dự án" để tạo/xem phòng chat

# TTDN-16-04-N9 - Các Module Odoo

Repository này chứa các module Odoo cho hệ thống quản lý doanh nghiệp.

## Các Module

### 1. Nhân Sự (nhan_su)
Module quản lý nhân viên, thông tin cá nhân, chức vụ, phòng ban.

### 2. Quản Lý Dự Án (quan_ly_du_an)
Module quản lý các dự án của công ty.

### 3. Quản Lý Công Việc (quan_ly_cong_viec)
Module quản lý công việc, phân công nhiệm vụ.

### 4. Thông Báo (thong_bao)
Module quản lý thông báo nội bộ.

### 5. Chat Nội Bộ (chat_noi_bo)
Module chat nội bộ giữa các nhân viên.

### 6. AI Chatbot (ai_chatbot)
Module chatbot AI hỗ trợ người dùng.

## Cài Đặt

1. Clone repository này vào thư mục addons của Odoo
2. Cập nhật danh sách module trong Odoo
3. Cài đặt các module cần thiết

## Yêu Cầu

- Odoo 16.0+
- Python 3.8+

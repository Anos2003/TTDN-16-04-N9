🚀 HƯỚNG DẪN NHANH

1️⃣ UPGRADE MODULE
   ```bash
   odoo -u thong_bao -d your_database
   ```

2️⃣ CLEAR CACHE
   ```bash
   find /mnt/extra-addons/thong_bao -name __pycache__ -exec rm -rf {} + 2>/dev/null
   ```

3️⃣ RESTART ODOO
   ```bash
   sudo systemctl restart odoo
   ```
